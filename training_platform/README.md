# Training Platform

Local Streamlit app for building a personal training platform.

## Folders

- `streamlit_app/` - the app source code
- `docs/` - practical instructions for running and using the app
- `notes/` - durable product decisions and requirements
- `prompts/` - editable AI coach prompt files

## Run

From PowerShell:

```powershell
Set-Location -LiteralPath "C:\Users\Urh\Desktop\Urh\Github Repositories\Training Peaks Custom Log\TrainingPeaks_customLog\training_platform"
.\start_app.cmd
```

Then open `http://127.0.0.1:8501`.
