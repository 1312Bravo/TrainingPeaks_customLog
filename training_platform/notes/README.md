# Training Platform Notes

This folder stores durable product and functionality notes for the training
platform.

Use these notes for:
- app functionality and workflows
- training data and graph requirements
- AI-coach behavior
- note-taking and saved-answer behavior
- privacy, sharing, deployment, and portability decisions
- architecture decisions that affect how the app works

Do not use these notes for small visual-only tweaks, such as table corner
rounding, colors, spacing, or one-off layout polish.

The notes should stay useful even if the platform is later rebuilt in another
tool or framework.
